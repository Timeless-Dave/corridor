## Hosted verification

The deployed Vercel proxy returned all four seeded flags. A new OpenAI
investigation of `collector_0` completed through the browser with a stored MONITOR
verdict. A second EventSource observer received 12 events over 22.321 seconds,
including `end`, demonstrating incremental forwarding through Vercel to Render.
Saved evidence, graph controls, replay, company context, and the M7 cross-account
memory case were opened on the hosted app. No browser page exceptions were
recorded. See [hosted evidence](m9-hosted-verification.json).

Render uses the supplied Docker service; the user's dashboard reports its
successful deployment. Local Docker execution remains untested because Docker
is unavailable here. Keep one API worker/instance: live jobs and SSE replay buffers
are process-local. The free Render service can sleep; allow for a cold start
before a live presentation. No graph reset was performed during hosted recording.

The API-docs link now uses a same-origin server redirect to the configured API
origin, so hosted visitors are not sent to localhost. Type checking and the
production build passed after this change.

## Film

The final MP4 is approximately 2:54, 1920×1080 at 30 fps, H.264 with AAC audio.
It includes a generated OpenAI Cedar voice, 45 synchronized caption cues, animated
original graph/typography cards, editorial zooms, real click highlights, and
half-second crossfades. The voice is explicitly labeled AI-generated. The
investigation scene is condensed for time; saved case sections are labeled.
The actual MONITOR outcome is retained, not replaced with a scripted FREEZE.

The narration was generated with `gpt-4o-mini-tts`. `whisper-1` word timestamps
were aligned to the written script; the differences were spelling/tokenization
of terms such as FalkorDB and MCP-related phrasing, not substantive content.
The script, capture automation, HTML/SVG cards, editor, caption alignment, and
mastering scripts are in [scripts/video](../scripts/video/README.md).

The film uses real hosted UI recordings and original motion graphics. No stock
music, cloned human voice, or invented evidence is included. See the
[video verification report](m9-video-verification.json) for export measurements.
