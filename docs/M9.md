## Local release

The root README now has exact dependency installation, remote-first environment
setup, explicit seeded loading, and the combined launcher `scripts/run-local.sh`.
The launcher never resets or seeds the graph. The existing Docker Compose file
starts only local FalkorDB and its Browser, not the API/frontend.

`api/Dockerfile` is a platform-neutral API image, built from the repository root:

```bash
docker build -f api/Dockerfile -t corridor-api .
docker run --rm --env-file .env -p 127.0.0.1:8000:8000 corridor-api
```

The image runs as an unprivileged user with one Uvicorn worker and respects `PORT`.
The Docker build context excludes credentials, generated datasets, and frontend
artifacts. Docker is unavailable on the current machine, so this image has not
been built or runtime-verified here. Native Python verification is separate.

## Hosting configuration

- API: persistent process/container, **one worker and one instance**. Inject the
  FalkorDB connection fields, `GRAPH_NAME`, `OPENAI_API_KEY`, and `OPENAI_MODEL`
  through the host's environment controls. Leave `CORRIDOR_ADMIN_TOKEN` unset.
  Use `/flags` for a database-aware health check. In-flight jobs and SSE replay
  buffers live in that process; scaling or restarts do not preserve the worker.
- Vercel: project root `web`, framework Next.js, install `npm ci`, build
  `npm run build`. Set server-only `CORRIDOR_API_URL` to the HTTPS API origin.
  The frontend proxy must be checked for incremental SSE on the deployed platform;
  local verification does not prove hosted function-duration/streaming behavior.
- The current application is a synthetic local demo without an authentication
  system. Do not treat publishing the existing investigation endpoint as a
  production multi-user deployment. Choose a controlled demo access arrangement
  before exposing model-spending endpoints publicly.

GitHub repository visibility and Vercel login were checked read-only. The GitHub
repository is public but had no default branch/content at the start of M9.
No API host has yet been selected or connected for this release. An optional
`render.yaml` at the repository root builds `api/Dockerfile` with health check
`/flags`; inject FalkorDB and OpenAI env vars in the host UI after the graph is loaded.
