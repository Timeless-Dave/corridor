# M6: investigation workspace

M6 adds the dark analyst workspace in `web/`: review queue, account history drawer,
live case evidence, Three.js graph, stored verdict and company context, and evidence
replay. Real data comes through the existing FastAPI endpoints; the running app has
no mock provider or fixture fallback.

## Run locally

Keep the API in one terminal:

```bash
cd api
../.venv/bin/uvicorn main:app --host 127.0.0.1 --port 8000
```

In a second terminal:

```bash
cd web
npm ci
npm run dev
```

Open http://localhost:3001. For a production frontend, run `npm run build`, then
`npm start`. If the API origin differs, set server-only `CORRIDOR_API_URL` in
`web/.env.local`; see `web/.env.example`. No database, model, or reset credentials
are exposed to the browser. The Next.js proxy allows only review/history/case
reads and investigation starts; it does not proxy admin reset or arbitrary paths.

## Interaction

- Queue shows the four persistent synthetic account flags, latest representative
  transfer, and prior-case status. Search by account ID. Open history to inspect an
  existing case or use Investigate to create a new one. Duplicate or unavailable
  starts have actionable errors and do not retry automatically.
- Desktop uses keyboard-resizable Evidence / Graph / Decision panels. Tablet and
  mobile use accessible tabs. Long evidence trails scroll independently and are
  not automatically scrolled away from the reader's current position.
- Select an evidence step to highlight its cited nodes. Only transfer IDs present
  in that finding's raw `transfers`, `edge_ids`, or `transfer_id` data highlight
  exact transfer edges. Other connections remain context. Rejected citations never
  enter the graph. Fixed Cypher is available in Technical details.
- Graph controls include orbit, pan, zoom, fit, and a flat orthographic view.
  Positions stay stable as new nodes arrive. Camera layout is presentational and
  does not imply a new risk score or clustering result. Shapes/colors distinguish
  accounts, devices, phones, policies, and decisions. Labels are Three.js sprites,
  avoiding nested DOM-root cleanup during graph unmounts.
- The accessible List view includes nodes and relationships. If WebGL is absent or
  fails, this remains the usable graph representation. Motion respects reduced
  motion preferences, and the graph renders on demand rather than continuously.
- A stored verdict displays model risk, policy/source, precedent/author, assignee,
  and deterministic guardrail reasons. “Why this decision?” replays the saved
  trail with previous, next, play, and pause controls. No control actually freezes
  money; this remains a synthetic demonstration.

## Streaming and compatibility

The server proxy forwards SSE bodies without buffering. Browser EventSource
reconnects with Last-Event-ID; event IDs prevent duplicate processing. Finding
updates coalesce into authoritative case reads, avoiding divergent provisional
and saved trails. On end, the stream closes and the final case is fetched again.
Restart snapshots are identified as restored evidence; an open case without a
live worker is displayed as interrupted, not completed. The M5 single-worker and
in-memory replay limitations remain.

Case detail adds `grounding` (policy, source document, precedent, author, assignee,
team), and `evidence[].query_text` for fixed allowlisted read tools. Internal
write/system queries are not exposed. Duplicate aggregate projections are normalized at the API boundary: members
are grouped by account ID with flagged-role precedence, and citation IDs are unique. Existing response fields and
verdict rules are preserved.

The approved frontend moves from the README's original Next.js 14 sketch to
Next.js 16.4.2 / React 19.3.1, with exact dependency versions in package-lock.json.
Node 24.15.0 was used. Self-hosted Geist fonts, Phosphor icons, Radix controls, and
custom Corridor tokens are shared throughout. React Bits and shadcn adaptations,
upstream license notices, and the unavailable 21st.dev component link substitution
are recorded in [web/SOURCES.md](../web/SOURCES.md). Impeccable's visual audit,
clarity, hardening, and polish guidance was applied as a review workflow; no plugin
installation or detector execution is claimed.
